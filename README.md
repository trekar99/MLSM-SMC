# Machine Learning for Sound and Music 

This repository contains my weekly assignments, code implementations, and practical experiments for the **Machine Learning for Sound and Music** course.

The course provides a comprehensive overview of deep learning techniques applied to audio analysis, ranging from traditional regression models to state-of-the-art Audio Transformers and Text-Audio multimodal models.

## 📘 Course Overview

* **Duration:** 10 Weeks (25 hours)
* **Format:** Weekly lectures followed by hands-on coding sessions.
* **Focus:** Practical application of ML algorithms to audio signal processing tasks.

## 📅 Syllabus & Assignments

Here is the breakdown of the topics covered each week and the corresponding work contained in this repo:

| Week | Topic | Description |
| :--- | :--- | :--- |
| **01** | **Introduction to ML & AI** | Overview of AI concepts and setting up the environment. |
| **02** | **Regression & Optimization** | Linear/Logistic regression and the mechanics of Gradient Descent. |
| **03** | **Traditional ML Algorithms** | Classification using k-Nearest Neighbors (kNN), Decision Trees, and SVMs. |
| **04** | **Artificial Neural Networks** | Introduction to Multi-Layer Perceptrons (MLP) and backpropagation. |
| **05** | **CNNs & Audio Representations** | Convolutional Neural Networks applied to Spectrograms and Mel-Spectrograms. |
| **06** | **Audio Autoencoders** | Unsupervised learning for dimensionality reduction and audio reconstruction. |
| **07** | **Metric Learning** | Learning embedding spaces using Triplet Loss and InfoNCE (Contrastive Learning). |
| **08** | **Audio Transformers** | Implementing Vision Transformers (ViT) and Attention mechanisms for audio. |
| **09** | **Embeddings & Transfer Learning** | Using pre-trained models for downstream tasks. |
| **10** | **Text-Audio Models** | Exploring multimodal models connecting natural language and sound. |
